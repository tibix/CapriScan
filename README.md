# CapriScan

**Logiciel SaaS de gestion de troupeau caprin — Agrilium**

CapriScan est un outil professionnel de gestion d'élevage caprin conçu par un éleveur pour les éleveurs. Il se compose de deux interfaces complémentaires :

- **CapriScan PC** — Inventaire, événements sanitaires, pharmacie, sessions de notation, calendrier sanitaire, rapports, contrôle laitier
- **CapriScan Mobile** — Notation à la traite (6 niveaux), suivi en temps réel, synchronisation cloud

🌐 **Application disponible sur :** [myagrilium.com](https://www.myagrilium.com)
